# RNN-VMC — 自旋 1/2 Heisenberg 的 RNN 变分蒙特卡洛

cRNN（复数相位，**不用 Marshall 符号**）计算 Heisenberg 链基态。
**完整工作记录（含方法/结果/接手指引）**：见 [`RNN-VMC工作记录.md`](RNN-VMC工作记录.md)。
**可移植完成版代码**：见 [`完成版/`](完成版/)（含基态 Adam+MARCH、激发态、2D、验证脚本，参照其 `README.md`）。

## 一句话现状（2026-08-15 完成）
L=10 PBC 自旋 1/2 反铁磁 Heisenberg 链，确定性模式 **E/site = -0.45148（相对 ED 0.013%）**；MC 模式（det 热身 + MC 微调）**-0.45126（0.063%）**。L=15/30 纯 MC 已跑（无 ED 基准，对照 Bethe 热力学极限）。参考：M. Hibat-Allah et al., PRX 10, 031017 (2020) [arXiv:2002.02973]。
